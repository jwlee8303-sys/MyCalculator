# PySide6 GUI 프로젝트

메인 화면에 다이나모와 단위환산 탭이 있습니다.

## 단위환산

속도, 압력, 질량, 길이, 토크, 에너지, 온도 영역마다 독립적인 변환 줄이 두 개 있습니다.
왼쪽 값을 입력하고 양쪽 단위를 선택하면 오른쪽 결과를 즉시 표시합니다.
결과는 선택해서 복사할 수 있으며, 빈 입력은 빈 결과로 표시합니다.
잘못된 입력은 결과 칸에 `입력 확인`으로 표시하고 마우스를 올리면 이유를 보여줍니다.
왼쪽 위 `소수점` 스핀박스는 모든 변환 결과에 일괄 적용되며 기본 2자리, 범위 0~12자리입니다.
반올림은 다이나모와 같은 ROUND_HALF_UP 방식이며 다이나모의 소수점 설정과는 독립적입니다.

- 속도: m/s, km/h, mph, ft/s, kn
- 압력: Pa, kPa, MPa, bar, mbar, psi, atm, kgf/cm², Torr
- 질량: kg, g, t, lbs
- 길이: m, cm, mm, km, ft, in, yd
- 토크·에너지: 다이나모와 동일한 단위
- 온도: °C, °F, K (절대영도 미만은 입력 오류)

환산 기준: [NIST SI 환산표](https://www.nist.gov/pml/special-publication-811/nist-guide-si-appendix-b-conversion-factors/nist-guide-si-appendix-b9).

## 다이나모 계산

운동에너지, 초기속도, 등가관성중량 중 두 값을 입력하고 나머지 입력란은 비워둡니다.
각 항목의 단위를 선택하고 계산하기를 누르거나 Enter를 누르면 결과를 표시합니다.
빈 입력란의 선택 단위가 결과 단위입니다. 입력값을 변경하면 이전 결과를 지우고, 단위를 변경하면 즉시 다시 계산합니다.
초기속도 결과에는 지름 120인치(3.048 m) 드럼의 회전수를 함께 표시합니다.
표시 예: `36.00 km/h (62.66 RPM)`. 공식은 `RPM = v[m/s] × 60 / (π × 3.048)`이며
초기속도 행의 소수점 자릿수 설정을 RPM에도 적용합니다. 입력한 속도와 계산한 속도 모두 적용하며,
바퀴 회전반경 입력값과는 별개의 고정된 드럼 지름을 사용합니다.
단위를 변경할 때 입력한 숫자는 유지되므로 원하는 단위의 값으로 입력하세요.

공식: E = ½mv². 등가관성중량은 질량(kg 기준)으로 취급하며, 속도는 0 이상입니다.
질량을 구할 때 속도는 양수, 속도를 구할 때 질량은 양수여야 합니다.
예: 속도 36 km/h, 등가관성중량 1000 kg → 운동에너지 50 kJ.

지원 단위:
- 운동에너지: J, kJ, MJ, Wh, kWh, ft-lbf, cal 및 kcal(열화학)
- 속도: m/s, km/h, mph, ft/s, kn
- 등가관성중량: kg, g, t, lb

계산 및 GUI 검증: `.venv\Scripts\python.exe -m unittest -v test_dynamo test_main`

## 실행

다이나모 계산 입력 영역에 제동거리와 감속도가 함께 있습니다.
초기속도를 공통으로 사용하며, 비워두면 운동에너지와 등가관성중량으로 계산한 속도를 사용합니다.
제동거리 또는 감속도 한 개를 입력하면 비워둔 항목의 선택 단위로 결과를 표시합니다.
입력 표는 항목 / 입력값 / 단위 / 결과 / 소수점 열로 구성됩니다.
계산하기 버튼 하나로 함께 계산하며, 계산된 값은 해당 항목의 결과 열에 단위와 함께 표시합니다.
입력값은 입력한 문자열 그대로 유지하며, 결과 칸에는 각 행의 소수점 설정으로 반올림한 값과 선택 단위를 표시합니다.
입력값을 바꾸면 이전 계산 결과를 지웁니다. 단위를 바꾸면 현재 입력값으로 즉시 다시 계산합니다. 입력 오류는 표 아래에 표시합니다.
초기화 버튼은 다섯 입력란과 두 결과를 모두 초기화합니다.
정지까지 일정하게 감속한다고 가정하며 반응거리를 포함하지 않습니다.
감속도는 양수로 입력합니다. 공식: a = v²/(2s), s = v²/(2a).

- 거리: m, cm, mm, km, ft, in, yd
- 감속도: m/s², g, km/h/s, ft/s², mph/s, cm/s²
- 예: 36 km/h, 10 m → 5 m/s² (약 0.509858 g)

## 바퀴 회전반경 및 제동토크

제동토크(T), 등가관성중량(m), 감속도(a), 회전반경(r) 중 세 값을 입력하면
비워둔 한 항목의 값을 표시합니다. 계산된 질량·속도·감속도는 다른 계산에도
연결되며 입력란은 그대로 유지합니다. 입력값을 바꾸면 결과와 계산식을 지우고, 단위를 바꾸면 즉시 다시 계산합니다.

기본식은 `T[N·m] = m[kg] × a[m/s²] × r[m]`입니다.
토크를 kgf·m로 표시할 때는 `T[kgf·m] = m × a × r / 9.80665`입니다.
감속도를 g로 선택하면 입력값에 9.80665를 곱해 m/s²로 변환합니다.
역산식은 `m = T/(a×r)`, `a = T/(m×r)`, `r = T/(m×a)`입니다.
네 항목은 유한한 양수로 입력합니다.

- 회전반경 단위: m, cm, mm, ft, in
- 제동토크 단위: N·m, N·cm, N·mm, kN·m, kgf·m, kgf·cm, lbf·ft, lbf·in
- 예: 1000 kg, 5 m/s², 300 mm → 1500 N·m (약 152.957 kgf·m)

회전반경은 바퀴 중심에서 접지면까지의 유효 반경이며 지름이 아닙니다.
이 식은 접선방향 제동력 `F = m×a`에 대한 토크 크기를 계산합니다.
바퀴 한 개의 토크를 계산할 때는 해당 바퀴에 배분된 등가관성중량을 입력합니다.
차량 전체 질량을 사용하면 같은 반경을 갖는 바퀴들의 합산 토크에 해당합니다.

## 계산 항목 안내

항목명 또는 결과 칸을 클릭하면 해당 값을 계산하는 데 필요한 행을 옅은 파란색으로
깜박여 표시하고, 계산하기 버튼 아래에 수식과 기준 단위를 표시합니다.
질량·감속도처럼 계산 방법이 여러 개이면 현재 입력값과 계산 결과가 가장 많이 준비된
방법을 표시합니다. 같은 칸을 다시 클릭하거나 화면의 다른 곳을 클릭하면 안내가 사라집니다.
다른 항목명이나 결과 칸을 클릭하면 해당 항목의 안내로 전환합니다.

## 기본 단위와 소수점 표시

각 행 맨 오른쪽 스핀박스로 소수점 자릿수를 0~12자리까지 설정합니다.
자릿수를 바꾸면 결과를 즉시 갱신하며, 5 이상은 올리는 반올림(ROUND_HALF_UP)을 사용합니다.
표시만 반올림하고 내부 계산과 연계 계산에는 원래 정밀도의 값을 사용합니다.
성공한 토크 계산의 보라색 수식 영역은 표시하지 않으며, 입력 오류 안내는 유지합니다.

| 항목 | 기본 단위 | 소수점 자릿수 |
|---|---|---|
| 운동에너지 | MJ | 0 |
| 초기속도 | ft/s | 2 |
| 등가관성중량 | lbs | 0 |
| 제동거리 | ft | 0 |
| 감속도 | ft/s^2 | 2 |
| 회전반경 | in | 1 |
| 제동토크 | lbf·in | 0 |

run.bat을 더블클릭하세요. PySide6가 없으면 먼저 설치합니다.
첫 설치에는 인터넷 연결이 필요합니다.

수동 설치 및 실행 (PowerShell):

```powershell
cd D:\MyCalculator
python -m venv .venv
.\.venv\Scripts\python.exe -m ensurepip --upgrade
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

이미 .venv가 있으면 가상환경 생성은 생략합니다.

## Windows 실행파일

`dist\MyCalculator.exe`는 Python 설치 없이 실행하는 단일 실행파일입니다.
Windows에서 `build.bat`을 실행하면 빌드 의존성을 설치하고 실행파일을 생성합니다.
빌드 설정은 `MyCalculator.spec`, 의존성은 `requirements-build.txt`에 있습니다.
`build/`와 `dist/`는 생성물이므로 Git 추적에서 제외합니다.
