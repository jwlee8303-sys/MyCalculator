# PySide6 GUI 프로젝트

메인 화면에 다이나모와 단위환산 탭이 있습니다. 단위환산 탭은 비워 두었습니다.

## 다이나모 계산

운동에너지, 초기속도, 등가관성중량 중 두 값을 입력하고 나머지 입력란은 비워둡니다.
각 항목의 단위를 선택하고 계산하기를 누르거나 Enter를 누르면 결과를 표시합니다.
빈 입력란의 선택 단위가 결과 단위입니다. 입력값 또는 단위를 변경하면 이전 결과를 지웁니다.
단위를 변경할 때 입력한 숫자는 유지되므로 원하는 단위의 값으로 입력하세요.

공식: E = ½mv². 등가관성중량은 질량(kg 기준)으로 취급하며, 속도는 0 이상입니다.
질량을 구할 때 속도는 양수, 속도를 구할 때 질량은 양수여야 합니다.
예: 속도 36 km/h, 등가관성중량 1000 kg → 운동에너지 50 kJ.

지원 단위:
- 운동에너지: J, kJ, MJ, Wh, kWh, ft-lbf, cal 및 kcal(열화학)
- 속도: m/s, km/h, mph, ft/s, kn
- 등가관성중량: kg, g, t, lb

계산 및 GUI 검증: `.venv\Scripts\python.exe -m unittest -v test_dynamo test_main`

## 실행

다이나모 계산 입력 영역에 제동거리와 감속도가 함께 있습니다.
초기속도를 공통으로 사용하며, 비워두면 운동에너지와 등가관성중량으로 계산한 속도를 사용합니다.
제동거리 또는 감속도 한 개를 입력하면 비워둔 항목의 선택 단위로 결과를 표시합니다.
입력 표는 항목 / 입력값 / 단위 / 결과 열로 구성됩니다.
계산하기 버튼 하나로 함께 계산하며, 계산된 값은 해당 항목의 결과 열에 단위와 함께 표시합니다.
입력값은 입력한 문자열 그대로 유지하며, 입력한 항목의 결과 칸에도 같은 값과 선택 단위를 표시합니다.
입력값이나 단위를 바꾸면 이전 계산 결과를 지웁니다. 입력 오류는 표 아래에 표시합니다.
초기화 버튼은 다섯 입력란과 두 결과를 모두 초기화합니다.
정지까지 일정하게 감속한다고 가정하며 반응거리를 포함하지 않습니다.
감속도는 양수로 입력합니다. 공식: a = v²/(2s), s = v²/(2a).

- 거리: m, cm, mm, km, ft, in, yd
- 감속도: m/s², g, km/h/s, ft/s², mph/s, cm/s²
- 예: 36 km/h, 10 m → 5 m/s² (약 0.509858 g)
